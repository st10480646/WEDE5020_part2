# OVRSIZ
**OVRSIZ** is a fictional, online streetwear brand founded in 2026. This project is a front-end web development school assignment focusing on semantic HTML structure and responsive CSS design.
## Project Overview
The website establishes a strong brand identity for a premium, gender-neutral, oversized clothing line. It targets Gen Z and younger millennials who value streetwear, comfort, and skate/hip-hop culture.
This project is built in two parts:
* **Part 1:** Core HTML structure, semantic elements, and content layout.
* **Part 2:** CSS styling, monochromatic color scheme with neon accents, brutalist typography, and mobile-first responsive design.
## Features
* **Mobile-First Responsive Design:** Fluid layouts using CSS Flexbox and Grid that adapt seamlessly to mobile, tablet, and desktop viewports.
* **Brutalist Design System:** 
  * Monochromatic palette (Black, Charcoal, White) with bold Neon Green accents.
  * Brutalist typography pairing `Impact`/`Arial Black` for headings and `Roboto` for highly readable body text.
* **Semantic HTML:** Accessible, well-structured HTML5 elements.
* **No External Frameworks:** Pure, vanilla CSS and HTML to keep the project beginner-friendly and lightweight.
## File Structure
```text
OVRSIZ/

├── about.html        # Brand identity, mission, and team
```

## Technologies Used
* **HTML5:** For page structure and semantic meaning.
* **CSS3:** For styling, Flexbox/Grid layouts, and media queries.
## How to Run
This is a static website with no build tools or dependencies required. 
1. Clone or download the repository to your local machine.
2. Open the `OVRSIZ` folder.
3. Double-click on `index.html` to open it in your default web browser.
